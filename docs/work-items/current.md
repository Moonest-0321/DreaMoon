## 使用流程與情境

1. 作者開啟一本書的設定與大綱工作區。
2. 作者進入「大綱」，在「故事背景」填寫並保存全書背景。
3. 作者建立前傳、單一主線、支線或後記；前傳／支線／後記可有多筆。
4. 作者替主線建立至少兩個階段。
5. 作者建立大綱項目，填寫標題、補充內容、四種手動狀態及手動順序。
6. 作者在「敘事大綱」與「時間軸」查看及編輯同一批項目；時間軸同時分欄顯示故事線。
7. 作者重新啟動程式後，內容、狀態、順序及 V1 遷移資料保持正確。

- 已知需評估狀態：主線已有一筆時的新增限制、窄 inspector、長內容、多故事線橫向閱讀、儲存錯誤與重新開啟。

- 線框／mockup／原型：待 R 批准後提出。

## 已決定事項與理由

- 第一版敘事大綱與時間軸直接讀寫同一筆 `OutlineItem`，不建立同步副本。
- 同一本書只有一條主線；多段發展由 `OutlineStage` 表達。
- 第一版採手動狀態與手填排序，不由正文或時間資料推定。
- 舊時間定位資料原樣保留，未定案前不自動轉換。
- 本輪需求尚未批准；上述既有決議不代表可選擴充已納入 V4.2。
