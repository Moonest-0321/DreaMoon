# 查找、替換與匯出功能規格（第一版）

> 狀態：依目前程式整理的既有行為
>
> 更新日期：2026-08-27

## 1. 查找與替換

- 查找範圍可選「本節次」或「全書」。
- 查找不區分大小寫。
- 可逐筆查看上一筆／下一筆結果。
- 啟用替換後，可替換目前結果或全部替換。
- 替換會保留被替換文字原本的格式屬性，並更新節與書籍的更新時間及字數。
- 替換後應重新整理結果，避免繼續操作過期位置。

## 2. TXT 匯出

- 可匯出整本書、單卷或單節。
- 匯出內容包含標題、作者、簡介（整本書）及依卷節順序排列的正文。
- 編輯器的幕標題會轉成較高層級的 `##` 文字標記。
- 目前匯出程式寫入使用者 Downloads 資料夾。

## 3. EPUB 匯出

- 可將整本書匯出為 EPUB 3 結構。
- 內容包含封面頁、導覽目錄、卷與節、樣式及書籍標題／作者中繼資料。
- 卷與節依目前排序輸出。
- 目前封面為文字排版封面；書籍封面圖片是否納入 EPUB 尚待確認。

## 4. 待確認決策

- 匯出是否應由使用者選擇目的地，而非固定 Downloads。
- 故事標籤、大綱、設定集資料是否要匯出。
- TXT 匯出副檔名與 Markdown 標記的正式相容性。
- EPUB 是否需要實際匯入書籍封面、版權與其他中繼資料。
- 全部替換是否需要預覽、撤銷或再次確認。
