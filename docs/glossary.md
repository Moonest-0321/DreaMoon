# 專案名詞表

> 本表只定義專案中使用的名詞；版本規劃、實作狀態與待決策事項請見其他文件。

| 名詞 | 定義 |
|---|---|
| 帆夢／Sailune | 協助創作者建構大型故事線與世界觀的軟體；也可單純作為文字編輯器使用。 |
| 書籍（Book） | 一個獨立的創作專案，包含正文與設定資料。 |
| 卷（Volume） | 書籍下的第一層正文組織單位。 |
| 節（Section） | 卷下的正文單位，包含節標題與 `AttributedString` 正文；這是產品文件與資料模型的正式用語。 |
| 章節 | 「節」的通用說法；使用者可以說章節，但程式、規格與資料模型統一使用「節」。 |
| 楔子 | 故事開場或正文前的敘事內容。 |
| 設定集 | 與正文並行的角色、物品、關係、時間軸等結構化資料總稱。 |
| 角色（Character） | 故事中的人物或具角色意義的個體。 |
| 真名 | 角色的主要識別名稱。 |
| 別名（Alias） | 角色除真名外可在正文中出現的名稱。 |
| 組織（Organization） | 故事世界中具有明確結構、成員或職能的運作單位；角色可以加入並擁有身分。組織可與陣營建立關聯，也可以獨立存在。 |
| 陣營 | 故事世界中代表共同立場、利益、目標或勢力集合的概念；不限定為特定政治、地理或制度形式。 |
| 能力（Ability） | 可被多個角色連接與共用的能力定義，具有階段與歷史；角色的持有／進度是另外的關聯資料。 |
| 物品（Item） | 一種共用的物品設定定義。 |
| 物品副本（Item Copy） | 某一件具體物品實體，可獨立設定名稱、持有人、等級與歷史。 |
| 持有人 | 目前持有某個物品副本或角色物品關聯的角色。 |
| 時間軸（Timeline） | 書籍中的一條世界時間序列。 |
| 紀元（Era） | 時間軸中的時間制度或時代區段。 |
| 時間釘子（Node） | 可被其他設定歷史與事件引用的時間定位點。 |
| 事件（Event） | 發生在時間軸上的敘事事件，可連結節與角色。 |
| 故事標籤（Story Tag） | 附著於正文選取文字的規劃標記，如主軸、支線、伏筆。 |
| 大綱 | 作者對故事方向、事件與結構的規劃資料。 |
| 故事背景 | 一本書的整體前提、世界基礎與故事方向，例如世界規則與終極目標；位於「大綱」底下，不是單一故事事件。 |
| 背景事件 | 故事中已存在的前因或經歷，可作為大綱項目，例如角色父母過去遭遇的事件。 |
| 故事線 | 為方便作者閱讀與整理而分開呈現的大綱內容線；V4.2 第一版包含前傳、主線、支線與後記。 |
| 大綱項目 | 作者手動輸入的一筆故事內容；V4.2 第一版由敘事大綱與時間軸直接共用同一筆資料。 |
| 修改註記 | 記錄某節或某段正文未來需要調整的內容。 |
| 正文引用 | 正文中與設定集項目建立的可跳轉連結。 |
| 文字錨點 | 由原始選取文字與 UTF-16 offset 組成的標記定位方式。 |
| 產品版本 | 使用者可感知的版本，例如 V4.0.1。 |
| schema 版本 | SwiftData 資料結構與遷移契約版本，例如 V1、V2、V3、V5。 |
