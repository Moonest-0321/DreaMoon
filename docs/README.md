## 文件使用方式

1. 開始工作前先讀「專案現況」與「功能盤點」。
2. 修改功能時讀取對應的功能規格。
3. 遇到未定案內容，保留在「待確認決策」，不要自行推定。
4. 完成工作後更新專案現況、相關規格與一致性檢查。
