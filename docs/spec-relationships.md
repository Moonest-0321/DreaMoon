# 關係與組織功能規格（第一版）

> 狀態：依目前程式整理的既有行為
>
> 更新日期：2026-08-27

## 1. 功能目的

呈現角色之間的互動、親屬與組織身分，讓作者能從清單或關係網檢視故事中的社會結構，並保留關係隨時間的變化。

## 2. 目前已確認行為

- 可建立一般角色關係，包含來源角色、目標角色、關係類型與備註。
- 可建立血緣關係，並以親屬角色表示。
- 關係詳情可編輯目前關係與歷史變化。
- 可在關係網檢視角色連線及方向。
- 角色可加入組織，記錄加入原因、備註與身分歷史。
- 組織屬於書籍，具有名稱與描述；代表具結構、成員或職能的運作單位，可與陣營建立關聯，也可獨立存在。
- 陣營代表共同立場、利益、目標或勢力集合；與組織的具體關聯方式及階層模型預計由 V5 建立。
- 角色、組織身分與關係歷史可指定時間定位。

## 3. 待確認決策

- 一般關係是否有固定詞彙或允許自由輸入。
- 關係 A→B 是否必須同時建立反向 B→A。
- 血緣關係是否需要限制循環、重複或自我關聯。
- 陣營與組織的實際關聯種類、階層、隸屬變更與獨立存在規則。
- 組織是否需要獨立列表、搜尋與正文引用。
- 關係網的顯示範圍、過濾與大型圖效能需求。

## 4. 驗收條件

- 能建立、編輯與刪除一般關係及血緣關係。
- 能在角色頁查看關係與關係歷史。
- 能將角色加入組織並記錄至少一段身分歷史。
- 能從關係網辨識來源與目標角色。
