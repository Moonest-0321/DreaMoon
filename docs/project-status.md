# 帆夢（Sailune）專案現況

> 帆夢：平凡的夢，或是揚帆的夢。

## 專案定位

帆夢是一套協助創作者建構大型故事線與世界觀的工具。它不只服務小說，也可以用於遊戲及其他需要管理複雜敘事、角色、設定與文本的創作。

## 專案目的

大型敘事作品通常包含大量設定集，但設定容易不完整、彼此矛盾，作者也不一定能清楚掌握自身故事的整體架構。帆夢希望透過軟體協助作者理解、整理並逐步完成自己的故事設定。

核心方向是：

- 讓作者更清楚地看見自身故事架構。
- 在儘可能無感的情況下，協助使用者逐步完成設定集。
- 提供方便、直覺的 UI／UX 與簡潔的工作流程。
- 讓使用者可以選擇使用相關設定功能，也可以單純把帆夢當作文字編輯器。
- 把文字編輯器本身做好，而不是只把它當成附屬功能。

## 使用範圍

- 小說與其他文學創作
- 遊戲劇情與世界觀設計
- 需要大型故事線、角色關係與設定管理的敘事型專案

## 協作原則（暫定）

- 文件描述產品意圖；程式與測試描述目前實際行為。
- 文件與程式不一致時，先記錄差異，再確認要更新哪一方。
- 不確定某個既有功能是否仍需要時，先保留並標記為待確認。
- 每次完成一個工作單元後，更新已完成項目、下一步與測試結果。
