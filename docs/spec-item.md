# 物品系統功能規格（第一版）

> 狀態：依目前程式整理的既有行為
>
> 更新日期：2026-08-27

## 1. 功能目的

管理故事中的物品定義，以及同一物品在世界中被不同角色持有的個別副本，讓作者能同時描述「物品是什麼」與「這一件物品經歷了什麼」。

## 2. 資料層次

1. **物品（Item）**：共用設定，如名稱、描述、分類、外觀材質、用途、正向能力與負向能力。
2. **物品等級（ItemLevel）**：物品設定中的等級資料。
3. **物品副本（ItemCopy）**：某一件具體實物，可有自己的名稱。
4. **副本持有人（ItemCopyHolding）**：副本目前由哪個角色持有。
5. **歷史（ItemHistory／ItemCopyHistory）**：物品或副本在故事時間中的紀錄。

## 3. 目前已確認行為

- 設定集側欄可新增、搜尋與編輯物品。
- 物品名稱不可為空白。
- 可建立多個副本；副本未設定自訂名稱時沿用物品名稱。
- 副本可指定或解除一名持有人。
- 副本可記錄目前使用的物品等級；此選擇不會自動改變物品名稱、能力、代價或歷史。
- 物品與副本皆可建立歷史，歷史可指定時間定位與關聯角色。
- 角色頁面可連接既有物品，並記錄持有數量。
- 物品詳情可顯示其在正文出現的節。
- 刪除物品會連帶刪除副本、持有人、副本等級選擇與歷史；正文文字保留。

## 4. 待確認決策

- 物品等級的正式用途：純設定階段，或未來會影響正文／副本狀態。
- 副本是否允許同時有多名持有人。
- 物品與副本歷史的差異及使用時機。
- 物品是否需要獨立的正文引用連結（目前介面已提供引用檢視）。
- 數量是否應支援零、負數或不可分割物品限制。

## 5. 驗收條件

- 能建立物品並填寫主要設定。
- 能建立兩個以上副本，分別設定名稱、持有人與等級。
- 能在物品與副本層級新增歷史並定位到時間軸。
- 刪除物品後不留下孤立的副本資料，且正文文字不被刪除。
