# 文字編輯器功能規格（第一版）

> 狀態：依目前程式整理的既有行為
>
> 更新日期：2026-08-27

## 1. 功能目的

提供穩定、低干擾的長篇文本寫作環境。作者可以專注寫作，也能在需要時查看設定集、連結角色與標記故事規劃，不必被複雜設定流程打斷。

## 2. 使用流程

1. 從書籍中進入編輯工作區。
2. 由左側目錄選擇卷與節。
3. 在中央編輯正文與節標題。
4. 需要時開啟右側「設定集」查看角色、能力、物品與標籤。
5. 透過上一節／下一節或目錄切換文本。
6. 內容自動儲存，完成後可匯出 TXT 或 EPUB。

## 3. 目前已確認行為

### 3.1 文本與節標題

- 每個節具有獨立標題與正文內容。
- 標題可直接在編輯區上方修改。
- 正文使用可捲動的文字編輯區，支援選取、編輯與復原。
- 中文輸入法組字期間會保留組字底線顯示。

### 3.2 段落樣式

- 正文與幕標題目前有兩種固定樣式。
- 可將游標所在段落切換為「幕標題／內文」。
- 可透過工具列或 `⌘2` 執行切換。

### 3.3 自動儲存

- 編輯內容會自動儲存。
- 介面提供「已儲存」、「儲存中…」、「儲存失敗」狀態。
- 切換節或背景同步設定集名稱前，會先提交尚未完成的儲存。
- 長篇內容載入時會延後排版，必要時顯示載入狀態。

### 3.4 導覽與工作區

- 左側目錄可顯示／隱藏。
- 右側設定集可顯示／隱藏。
- 支援上一節、下一節。
- 提供指令面板與快捷鍵說明。

### 3.5 角色引用

- 可辨識正文中與角色真名或別名完全相符的文字。
- 已連結的角色文字可開啟對應角色設定。
- 選取角色名稱時，可在編輯器上方顯示角色資訊列。
- 對尚未建立的名稱，可從編輯流程建立新角色。
- 角色名稱同步時，會處理正文中的既有連結並提示未連結的舊名稱。

### 3.6 故事規劃與標籤

- 每一節可開啟「預定大綱」與「修改註記」。
- 選取正文文字後，可建立故事標籤。
- 故事標籤會以不同顏色在正文中標記。

## 4. 非目標（目前不應假設）

- 編輯器不是通用排版軟體；目前沒有完整字型、尺規或自由格式工具的規格。
- 設定集功能是可選的；正文編輯不應要求作者先建立角色、物品或標籤。
- 角色引用辨識不代表所有同名文字都必然是該角色，歧義時應避免自動誤連結。

## 5. 待確認的產品決策

- 是否需要更多正文樣式（例如引用、列表、分隔線）。
- 「幕標題」的正式語意：場景標題、段落標題，或其他用途。
- 自動儲存失敗時的重試、提示與復原流程。
- 是否需要顯示字數以外的統計，例如閱讀時間或段落數。
- 角色引用的建立規則是否要支援更多觸發方式。
- 編輯器是否需要支援 Markdown、RTF 或其他匯入格式。

## 6. 驗收條件（目前版本）

- 能建立或開啟一個節並編輯標題與正文。
- 切換節後，前一節的內容已保存且不被覆蓋。
- 重新開啟專案後，正文與樣式仍可正常顯示。
- 可在正文中開啟已連結角色，且不會因歧義名稱誤連結。
- 可選取文字建立故事標籤，並在正文中看見標記。
- 編輯器可在不開啟設定集的情況下單獨完成寫作。
