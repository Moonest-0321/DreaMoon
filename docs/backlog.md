## V4：標籤、大綱

### 版本目標

讓作者能在寫作過程中保留故事主軸、支線、伏筆、修改與計劃內容，並以大綱輔助正文推進。

### 目前已存在

- 故事標籤：主軸、支線、伏筆、修改、計劃加入。
- 每節預定大綱與修改註記。
- 標籤文字錨點與正文中的顏色提示。

### V4.2 第一版（已實作）

- 在大綱底下新增全書層級的故事背景；它與大綱項目的背景狀態是不同概念。
- 大綱分為敘事大綱與時間軸，兩處共用同一筆大綱內容並同步更新。
- 現有時間軸產品設計將由 V4.2 打掉重做，不在旁邊保留另一套平行的規劃時間軸。
- 故事線分為前傳、主線、支線與後記；可建立多個前傳、支線與後記，主線每本書一條且可分段。
- 時間軸同時分欄呈現不同故事線，方便作者比較整體安排。
- 大綱項目以背景、已發生、草稿、預定呈現狀態。
- 第一版採手動輸入與手填排序，不嫁接正文、節、故事標籤或時間釘子，也不處理敘事順序與世界時間順序的差異。
- 完整需求與非目標見 `docs/prd-v4.2-outline.md`。

### 仍需確認／完成

- 標籤列表、篩選、統計與完成狀態。
- 舊時間定位相容層的最終退場或轉換；第一版已確定保留原資料且不自動轉換。
- V4.2 大綱項目與節、故事標籤及其他設定歷史的正式關聯。
- 故事背景的進階結構化欄位，以及故事線／階段／大綱項目的刪除與復原。
- 標籤與大綱是否納入 TXT／EPUB 或其他專案匯出。
- 現有 V4.0.1「標籤更新」提交與本版本計劃的對應關係。
- 正式簽章／封裝、人工 UI 流程與正式發布標記（屬 V4.2 發布前工作）。

## V5：陣營及其他設定

### 版本目標

擴充角色以外的世界觀設定，讓作者能管理陣營及其與角色、組織、事件、地點或物品的關係。

### 初步範圍

- 陣營資料模型與基本設定；描述共同立場、利益、目標或勢力集合，不預設固定制度或層級。
- 陣營與組織的可能關聯；組織可獨立存在，也可與一個或多個陣營建立關係。
- 陣營成員、對立、合作與變化歷史。
- 陣營與事件、時間軸及正文引用的連結。
- 其他尚未分類但屬於世界觀的設定類型。

### 仍需確認／完成

- 陣營與現有「組織」的實際關聯種類、階層與邊界。
- 陣營是否可以直接關聯角色、其他陣營或事件，以及組織在其中扮演的角色。
- 其他設定的第一批具體類型，不在未定義前預先建立泛用模型。
- V5 schema 與既有 V5 資料庫的產品版本對應方式。

## V6：UI 與可靠性更新

### 版本目標

改善操作一致性、效能、錯誤回復與資料安全，讓大型專案長時間使用時仍穩定可靠。

### 初步範圍

- UI／UX 一致性與工作區流程整理。
- 長篇正文載入與編輯效能。
- 自動儲存失敗提示、重試與復原。
- 多 store 備份、還原與一致性檢查。
- 匯出目的地與錯誤處理改善。
- 刪除資料的復原或更清楚的不可復原流程。

### 仍需確認／完成

- V6 的可靠性指標，例如可接受的啟動時間、儲存延遲與資料遺失上限。
- 是否支援自動備份、備份版本保留與一鍵還原。
- UI 改版是否維持既有快捷鍵與工作流程相容。

## V7：地圖更新

### 版本目標

加入地圖及地理空間設定，使地點、移動、事件與世界觀資料能與故事時間軸及正文互相連結。

### 初步範圍

- 地圖與地點資料。
- 地點之間的層級、連線或距離。
- 角色、組織、物品與事件的地點關聯。
- 地圖資料與時間軸變化的關聯。

### 仍需確認／完成

- 地圖是圖片標註、向量地圖，還是結構化地點圖。
- 是否需要多張地圖、不同時代版本或平行世界地圖。
- 地圖資料是否需要匯出，以及與外部地圖格式的相容性。
- V7 地圖模型與 V5 陣營、V6 可靠性工作的依賴關係。

## 優先順序原則

- 先完成目前版本的核心驗收，再擴充下一版本的資料模型。
- 先處理會影響資料安全與長期維護的 V6 基礎工作，再加入高耦合的新設定類型。
- 新增設定類型前，先確認它與角色、組織、時間軸、事件及正文引用的關聯方式。
- 未定義的「其他設定」先保留為規劃項目，不建立沒有明確用途的泛用欄位。
