# 故事規劃與標籤功能規格

> 狀態：V4.0.1 標籤／每節註記與 V4.2 全書規劃均已實作
>
> 更新日期：2026-09-01

## 1. 功能目的

讓作者在寫作過程中，以低干擾方式標記主軸、支線、伏筆、修改與預計補寫內容，為每一節保留大綱與修改註記，並在全書層級整理故事背景與故事線。

## 2. 目前已確認行為

- 故事標籤附著於指定書籍與節的選取文字。
- 標籤類型包含：主軸、支線、伏筆、修改、計劃加入。
- 標籤保存標題、原始選取文字與文字位置。
- 編輯器會在正文中以顏色提示標籤；標籤本身不改變正文語意。
- 文字前方插入或刪除後，系統會以原文字及原位置尋找最接近的標記位置。
- 每一節可保存一份預定大綱與一份修改註記。
- 每本書可保存一筆全書故事背景。
- 工作區頂層為「設定集／大綱」；大綱底下為「故事背景／敘事大綱／時間軸」。
- 可建立前傳、主線、支線與後記；前傳、支線與後記可有多筆，主線每本書一條且可分成多個階段。
- 全書大綱項目可手動設定背景、已發生、草稿或預定狀態及排序。
- 敘事大綱與新時間軸讀寫同一筆 `OutlineItem`，不另建同步副本。
- 新時間軸同時分欄顯示各故事線，方便作者直接比較不同內容線。
- 全書大綱不要求正文、節、故事標籤或舊時間釘子連結。

## 3. 待確認決策

- 標籤標題是否必須由作者輸入，或可由選取文字自動產生。
- 標籤能否跨節、重疊或套用至空白範圍。
- 文字重複出現時，最近位置推定失準的提示方式。
- 標籤是否需要列表、篩選、統計與完成狀態。
- 大綱與修改註記是否要納入匯出檔案。
- 全書大綱與正文、節、標籤、設定歷史及舊時間定位的正式關聯。
- 故事線、主線階段與大綱項目的刪除、復原、搜尋、篩選與大量操作。

## 4. 驗收條件

- 能在選取正文後建立五種標籤中的任一種。
- 重新載入節後標籤仍顯示在合理位置。
- 修改正文前段後，標籤能儘量維持在原段落。
- 能開啟、編輯並保存每節的大綱與修改註記。
- 能建立、編輯並重開故事背景、四類故事線、至少兩個主線階段與四種狀態的大綱項目；同一本書不能建立第二條主線。
- 手動排序在重開 store 後維持穩定。
- 從敘事大綱或新時間軸修改同一筆項目時，另一呈現取得相同內容且資料庫中只有一筆項目。
- V1 store 升級後，既有故事標籤 UUID／錨點與每節註記不變。

## 5. V4.2 第一版（已實作）

V4.2 已在「大綱」底下新增全書層級的故事背景，並提供敘事大綱與共用大綱資料時間軸。故事線包含前傳、主線、支線與後記，第一版採手動輸入、手填排序。

資料使用獨立故事規劃 store 的 `StoryPlanningSchemaV2`；舊標籤與每節註記由 V1 lightweight migration 保留。完整產品範圍、非目標、驗收證據與待確認事項見 `docs/prd-v4.2-outline.md`。
