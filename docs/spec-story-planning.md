# 故事規劃與標籤功能規格

> 狀態：V4.4 寬版大綱工作區已實作，待人工 UI 冒煙；每節註記仍為獨立功能
>
> 更新日期：2026-09-05

## 1. 功能目的

讓作者在寫作過程中，以低干擾方式將主線、支線與預計補寫內容直接納入全書大綱；伏筆與修改仍作為正文標記，並為每一節保留獨立註記。

## 2. 目前已確認行為

- 故事標籤附著於指定書籍與節的選取文字。
- 標籤類型包含：主軸、支線、伏筆、修改、計劃加入。
- 「伏筆／修改」標籤保存標題、原始選取文字與文字位置；設定集的標籤頁只列出這兩種。
- 從正文可建立「加入主線大綱／新增支線大綱／加入主線草稿」：每次皆建立新大綱項目，支線同時新建故事線；主線不存在時自動建立。
- 由正文建立的大綱項目保存零或一筆 `OutlineItemAnchor`，可在右側大綱以「來源：回到正文」回跳；editor 會以顏色提示來源，且不改變正文語意。
- 可刪除大綱項目（含其來源）、故事線（級聯其階段、項目與來源）、主線階段（級聯其項目與來源）及伏筆／修改標籤；每次均需確認，正文與每節註記保留，且不提供復原。
- 文字前方插入或刪除後，系統會以原文字及原位置尋找最接近的標記位置。
- 每一節可保存一份預定大綱與一份修改註記。
- 每本書可保存一筆全書故事背景。
- 寫作區右側設定集保留「設定集／大綱」，其中大綱只包含敘事大綱與時間軸；故事背景改由書籍總覽進入。
- 寫作工具列以「設定集｜大綱｜快捷鍵」排列右側按鈕；大綱按鈕會在同一書籍視窗中以寬版工作區取代中央文本，並隱藏左側正文目錄。工作區可直接回到文本，具正文來源的項目可回到原節與原文位置。
- 可建立前傳、主線、支線與後記；前傳、支線與後記可有多筆，主線每本書一條且可分成多個階段。
- 手動大綱只可設定背景、草稿或預定；「已完成」沿用已發生的儲存值且必須有正文來源。正文「加入主線草稿」仍為草稿，不因有來源而顯示完成。舊手動已發生資料保留並提示調整。
- 敘事大綱與新時間軸讀寫同一筆 `OutlineItem`，不另建同步副本。
- 寬版時間軸以幕／節次作橫軸、故事線作橫向泳道，方便作者比較不同內容線。它只表達書籍結構順序，不代表故事世界的絕對年代。
- 手動建立的全書大綱不要求正文；只有正文建立或 V2 結構標籤遷移的項目帶有來源錨點。
- 故事背景提供世界／時代背景、故事前提、主要衝突、主角目標、核心主題五個選填引導，並保留其他背景自由文字區；既有自由文字會原樣讀取。
- 書籍總覽的資訊順序為基本資訊、封面、簡介、故事背景、統計；故事背景先顯示摘要卡，展開後以總覽完整寬度編輯同一筆背景資料。
- 同一故事線或主線階段內，正文項目依卷／節和目前文字位置排序；手動項目可安置於幕首、幕末或某項目後，同位置可上／下移動。舊資料缺少安置紀錄或掛點失效仍須可見，首次安置才建立紀錄；掛點跨階段移動或刪除時，依附項目回待安置並保留內容。
- 未分階段與每個主線階段預設收起；新增主線項目預設進入最後階段，且項目可移至其他階段或未分階段。
- 正文新增主線／主線草稿時，先依來源節次尋找最近且不晚於正文位置的階段起點；無法對應（缺起點、來源無法定位或在所有起點之前）時放入畫面排序的最後階段。主線尚無階段才保留未分階段；不改寫舊項目的歸屬或失效的階段起點。
- 刪除主線階段時，直接刪除所屬大綱項目與其正文來源標記；正文內容保留，不將項目移至未分階段。
- 主線階段以既有書籍結構的幕／節次指定開始位置；來源被刪除時保留最後名稱並顯示「來源已刪除」，不自動改指向其他位置。
- UI 的「已完成」只適用正文來源項目；手動項目可為背景、草稿或預定。手動項目以幕首、幕末、接在項目後或待安置控制位置，不提供數字排序輸入。
- 時間軸只將可解析至幕／節次的項目放入泳道欄位；待安置、失效來源、循環掛點或其他無法解析的位置固定顯示在底部待安置區，不猜測時間座標。

## 3. 待確認決策

- 標籤標題是否必須由作者輸入，或可由選取文字自動產生。
- 伏筆／修改標籤能否跨節、重疊或套用至空白範圍。
- 文字重複出現時，最近位置推定失準的提示方式。
- 標籤是否需要列表、篩選、統計與完成狀態。
- 大綱與修改註記是否要納入匯出檔案。
- 全書大綱與設定歷史及舊時間定位的正式關聯。
- 搜尋、篩選與大量操作。

## 4. 驗收條件

- 能在選取正文後建立伏筆、修改或三種對應大綱動作。
- 重新載入節後，標籤與具來源的大綱項目仍顯示在合理位置。
- 修改正文前段後，標籤與大綱來源錨點能儘量維持在原段落。
- 能開啟、編輯並保存每節的大綱與修改註記。
- 能建立、編輯並重開故事背景、四類故事線、至少兩個主線階段與四種狀態的大綱項目；同一本書不能建立第二條主線。
- 沒有有效正文來源的項目在重開 store 後維持穩定後備順序。
- 從敘事大綱或新時間軸修改同一筆項目時，另一呈現取得相同內容且資料庫中只有一筆項目。
- 能從編輯器工具列開啟無左側正文目錄的寬版大綱工作區，切換垂直敘事大綱與橫向泳道時間軸，並回到文本或正文來源。
- 書籍總覽能顯示故事背景摘要，展開後可在完整寬度編輯，舊自由文字與結構化背景均保持可讀。
- V3 升級後，V2 主軸／支線／計劃加入轉為同 UUID 的大綱項目與來源錨點並移除舊標籤；伏筆／修改 UUID／錨點與每節註記不變。

## 5. V4.2 第一版（已實作）

V4.2 已在「大綱」底下新增全書層級的故事背景，並提供敘事大綱與共用大綱資料時間軸。故事線包含前傳、主線、支線與後記，第一版採手動輸入、手填排序。

資料使用獨立故事規劃 store 的 `StoryPlanningSchemaV3`；V1→V2 保留原資料，V2→V3 新增大綱來源錨點後於 store 開啟時轉換結構標籤。完整產品範圍、非目標、驗收證據與待確認事項見 `docs/prd-v4.2-outline.md`。
