# 故事規劃與標籤功能規格

> 狀態：現況已具寬版橫向敘事畫布、右側唯讀導覽，以及由既有大綱建立世界時間事件的入口
>
> 更新日期：2026-09-14

## 1. 功能目的

讓作者在寫作過程中，以低干擾方式將主線、支線與預計補寫內容直接納入全書大綱；伏筆與修改仍作為正文標記，並為每一節保留獨立註記。

## 2. 目前已確認行為

- 故事標籤附著於指定書籍與節的選取文字。
- 現行 `StoryTag` 類型只有伏筆與修改。舊版主軸、支線與計劃加入資料在 StoryPlanning V2→V3 遷移時轉為大綱項目；正文選單目前直接建立大綱，不再建立這三種結構標籤。
- 「伏筆／修改」標籤保存標題、原始選取文字與文字位置；設定集的標籤頁只列出這兩種。
- 從正文可建立「加入主線大綱／新增支線大綱／加入主線草稿」：每次皆建立新大綱項目，支線同時新建故事線；主線不存在時自動建立。V4.4.9 的文本右鍵選單直接顯示「敘事大綱／修改／草稿」：前者對應加入主線大綱，後兩者分別沿用修改標記與加入主線草稿行為。
- 由正文建立的大綱項目保存零或一筆 `OutlineItemAnchor`，可在右側大綱以「來源：回到正文」回跳；editor 會以顏色提示來源，且不改變正文語意。
- 可刪除大綱項目（含其來源）、故事線（級聯其階段、項目與來源）、主線階段（級聯其項目與來源）及伏筆／修改標籤；每次均需確認，正文與每節註記保留，且不提供復原。
- 文字前方插入或刪除後，系統會以原文字及原位置尋找最接近的標記位置。
- 每一節可保存一份預定大綱與一份修改註記。
- 每本書可保存一筆全書故事背景。
- 寫作區右側設定集保留「設定集／大綱」，其中大綱只包含敘事大綱與時間軸；故事背景改由書籍總覽進入。
- 寫作工具列的主要操作依序為「指令｜更多｜大綱｜設定集」，設定集固定於最右端以對應右側 inspector。大綱按鈕會在同一書籍視窗中以寬版工作區取代中央文本，並隱藏左側正文目錄；V4.4.3a 起同一位置會改為「回到文本編輯」，回到文本後恢復「大綱」。具正文來源的項目可回到原節與原文位置。
- 可建立前傳、主線、支線與後記；前傳、支線與後記可有多筆，主線每本書一條且可分成多個階段。
- 手動大綱只可設定背景、草稿或預定；「已完成」沿用已發生的儲存值且必須有正文來源。正文「加入主線草稿」仍為草稿，不因有來源而顯示完成。舊手動已發生資料保留並提示調整。
- 敘事畫布的所有呈現讀寫同一筆 `OutlineItem`，不另建同步副本。現行世界時間軸則讀寫主 store `Event`；可由既有 OutlineItem 建立 Event，並由 `TimelineEventCardMetadata` 保存關聯與節錄設定，但兩者不是同一筆資料。
- V4.4.1 的寬版敘事大綱以卷次／節次作橫軸、故事線作橫向泳道，方便作者比較正文揭露順序、故事線穿插與事件密度。主線階段以起點至下一階段前一節的淡色區段呈現；失效或待設定起點不猜測範圍。
- V4.4.2 正名書籍結構為卷次／節次，並在其下加入既有幕標題層級。段落仍是作者可添加的大綱內容，不會自動成為欄位或卡片。階段開始可停在卷次、節次或幕標題；單線入口預設主線。
- V4.4.2a 敘事畫布左欄固定，右側內容水平捲動，兩側共用垂直捲動並依內容高度對齊；水平座標不回寫畫面狀態。工具列保留「指令」及 ⌘K，快捷鍵說明由指令面板開啟，不再另外顯示快捷鍵按鈕。
- 敘事階段帶依所選卷次、節次或幕標題對應到起始欄，延伸到下一個不同階段起點前一欄；最後階段延伸到全書最後欄。同一節內不同幕標題的階段起點必須分開呈現。
- 「時間軸」頁籤目前已接回 `Timeline`、`Era`、`Node`、`Event` 世界時間模型；V4.4.1 曾與敘事大綱共用 OutlineItem 的畫面只屬歷史過渡狀態。
- 手動建立的全書大綱不要求正文；只有正文建立或 V2 結構標籤遷移的項目帶有來源錨點。
- 故事背景提供世界／時代背景、故事前提、主要衝突、主角目標、核心主題五個選填引導，並保留其他背景自由文字區；既有自由文字會原樣讀取。
- 書籍總覽的資訊順序為基本資訊、封面、簡介、故事背景、統計；故事背景先顯示摘要卡，展開後以總覽完整寬度編輯同一筆背景資料。
- 同一故事線或主線階段內，正文項目依卷／節和目前文字位置排序；手動項目可安置於幕首、幕末或某項目後，同位置可上／下移動。舊資料缺少安置紀錄或掛點失效仍須可見，首次安置才建立紀錄；掛點跨階段移動或刪除時，依附項目回待安置並保留內容。
- 正文來源的錨定文字在成功儲存後若已完全不存在，項目不刪除也不進待安置：保留原節次、故事線與階段，錨點降級為該節開頭並將狀態改為草稿。「回到正文」仍跳至該節開頭；不顯示不確定狀態，也不跨節猜測位置。
- V4.4.81 的伏筆／修改是輕量正文標記：成功儲存後，原錨定文字若在同節完全不存在就直接刪除該 StoryTag，不建立草稿或失效狀態。文字只改格式或同節位置時仍依最近舊 offset 跟隨；其他有效標記、大綱與每節註記不受影響。
- 同一書籍視窗內，若 StoryTag 刪除或 OutlineItem 節首草稿降級是由可復原的正文編輯引起，標準 Undo／Redo 以原 UUID 快照同步恢復／重做規劃變化；不提供跨視窗或跨啟動歷史。
- 未分階段與每個主線階段預設收起；新增主線項目預設進入最後階段，且項目可移至其他階段或未分階段。
- 正文新增主線／主線草稿時，先依來源節次尋找最近且不晚於正文位置的階段起點；無法對應（缺起點、來源無法定位或在所有起點之前）時放入畫面排序的最後階段。主線尚無階段才保留未分階段；不改寫舊項目的歸屬或失效的階段起點。
- 刪除主線階段時，直接刪除所屬大綱項目與其正文來源標記；正文內容保留，不將項目移至未分階段。
- 主線階段以既有書籍結構的幕／節次指定開始位置；來源被刪除時保留最後名稱並顯示「來源已刪除」，不自動改指向其他位置。
- UI 的「已完成」只適用正文來源項目；手動項目可為背景、草稿或預定。手動項目以幕首、幕末、接在項目後或待安置控制位置，不提供數字排序輸入。
- 橫向結構畫布只將可解析至幕／節次的項目放入泳道欄位；待安置、失效來源、循環掛點或其他無法解析的位置固定顯示在底部待安置區，不猜測正文位置。
- V4.4.4 的寬版敘事大綱使用一致的主要／次要按鈕層級：常用與破壞性動作以文字搭配圖示呈現並增加點擊高度；管理入口明示為「管理故事線與階段」，項目詳情中的狀態、階段與位置顯示語意前綴。操作順序與資料行為不變；右側窄欄不列為本版完成範圍。
- V4.4.5 的寬版敘事大綱依既有故事線、階段與正文／手動安置順序，垂直顯示項目標題；不顯示摘要、狀態或來源。故事線與階段／未分階段／待安置可個別收合，狀態只存在目前畫面。
- 具有效正文來源的標題整列可直接返回原節與文字位置；手動項目或失效來源不猜測正文位置，改為開啟既有項目詳情。管理故事線與階段的入口及右側窄欄維持原行為。
- V4.4.5a 的右側敘事大綱只顯示依既有敘事投影攤平的標題。有效正文來源顯示跳轉箭頭並可回到精確文字位置；手動或失效來源只顯示標題，不提供詳情或編輯。故事線、階段、摺疊及所有管理控制只保留在寬版工作區。
- V4.4.5b 修正跨節正文跳轉時序：目標節正文完成載入後才套用錨點選取、捲動與焦點，避免載入流程重設游標；同節跳轉維持立即定位。相同文字重複出現時仍以舊 offset 最近候選為準。
- V4.4.7 寬版敘事大綱恢復 V4.4.4a 的橫向卷次／節次／幕標題畫布、固定故事線左欄、主線階段帶、卡片與待安置區；V4.4.5a 右側唯讀清單及 V4.4.5b 精確正文跳轉維持不變。
- 寬版敘事大綱頂部提供「從敘事大綱加入時間軸」；本書所有既有項目皆可加入。作者須先在敘事畫布選定卡片，未選時入口停用；表單固定顯示該來源，不提供再次選擇來源。節錄來源固定為內文自動節錄，不提供手動自填。表單自動帶入最多 10 字標題與詳情，作者在加入當下指定世界時間；正文來源形成實線卡，手動項目形成顯示「尚無正文來源」的虛線卡。成功後停留在敘事大綱並顯示完成提示。
- 文本與大綱工作區在同一書籍視窗中保留各自生命週期；大綱首次使用才載入。敘事畫布使用規劃資料與卷節更新 revision 驅動的記憶體快取，單純切換、捲動、列高或選取不重新解析全書。

## 3. 待確認決策

- 標籤標題是否必須由作者輸入，或可由選取文字自動產生。
- 伏筆／修改標籤能否跨節、重疊或套用至空白範圍。
- 文字重複出現時，最近位置推定失準的提示方式。
- 伏筆／修改已有列表與正文跳轉；待確認的是篩選、統計，以及伏筆的未回收／已回收狀態、回收位置與完成流程。
- 大綱與修改註記是否要納入匯出檔案。
- 全書大綱與設定歷史及舊時間定位的正式關聯。
- 搜尋、篩選與大量操作。

## 4. 驗收條件

- 能在選取正文後建立伏筆、修改或三種對應大綱動作。
- 重新載入節後，標籤與具來源的大綱項目仍顯示在合理位置。
- 修改正文前段後，標籤與大綱來源錨點能儘量維持在原段落。
- 能開啟、編輯並保存每節的大綱與修改註記。
- 能建立、編輯並重開故事背景、四類故事線、至少兩個主線階段與四種狀態的大綱項目；同一本書不能建立第二條主線。
- 沒有有效正文來源的項目在重開 store 後維持穩定後備順序。
- 從不同敘事大綱呈現修改同一筆項目時，其他敘事呈現取得相同內容且規劃 store 中只有一筆項目。世界時間 Event 可保留 OutlineItem 關聯，但不要求兩者內容雙向同步。
- 能從編輯器工具列開啟無左側正文目錄的寬版大綱工作區；敘事大綱以卷次／節次／幕標題橫軸及故事線列呈現，正文來源可直接跳轉，無可靠位置者保留在待安置區並可開啟詳情。
- 寬版敘事大綱的管理、建立、重新定位、儲存及刪除操作可直接由按鈕文字辨識，主要、次要與破壞性層級一致，且選取卡片能辨識其對應詳情。
- 書籍總覽能顯示故事背景摘要，展開後可在完整寬度編輯，舊自由文字與結構化背景均保持可讀。
- V3 升級後，V2 主軸／支線／計劃加入轉為同 UUID 的大綱項目與來源錨點並移除舊標籤；伏筆／修改 UUID／錨點與每節註記不變。

## 5. V4.2 第一版（已實作）

V4.2 已在「大綱」底下新增全書層級的故事背景，並提供敘事大綱與共用大綱資料時間軸。故事線包含前傳、主線、支線與後記，第一版採手動輸入、手填排序。

資料使用獨立故事規劃 store 的 `StoryPlanningSchemaV3`；V1→V2 保留原資料，V2→V3 新增大綱來源錨點後於 store 開啟時轉換結構標籤。完整產品範圍、非目標、驗收證據與待確認事項見 `docs/prd-v4.2-outline.md`。
## 設定時間序投影（V4.4.81）

- 人物、能力、外觀、心理、物品、副本、組織與一般關係的時間序以原始紀錄為唯一內容來源。
- Node 有有效世界日期時投影到世界時間軸；有本書節次時投影到敘事大綱；兩者可同時存在。
- `Node.isVisible` 是「顯示於規劃視圖」總開關，關閉時兩種投影都隱藏但資料與歸屬保留。
- 敘事投影只定位至節次；故事線與可選階段按來源 UUID 保存，不寫入共用 Node，也不建立正文錨點。
- 既有資料沒有故事線時顯示於「未分類時間序」，不自動猜測、不改成草稿。投影卡片唯讀，點擊回來源設定。
