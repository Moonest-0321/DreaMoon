# ADR-004：產品版本與 schema 版本分離

- 狀態：Accepted
- 日期：2026-08-31
- 相關版本：產品 V2–V7；schema V1、V2、V3、V5

## 背景

Git 歷史中的產品版本命名曾有不同格式與順序；資料 schema 版本則反映資料庫結構，不一定與產品功能版本同步。

## 決策

產品版本使用 `V主版本.次版本.修訂版`，記錄使用者可感知的功能變更。schema 版本只在資料結構或遷移契約改變時增加。兩者分別記錄在 `CHANGELOG.md`、遷移文件與程式 schema 宣告中。

## 影響

- 不修改歷史 Git 提交訊息來修正版本順序。
- 發布檢查需確認產品版本、schema 版本與資料遷移測試各自完成。
- 文件不可用單一「版本」欄位同時表示兩種概念。

## 後續檢討條件

若未來導入自動化版本發布或套件化 schema 管理，可重新定義命名工具，但仍維持語意分離。
