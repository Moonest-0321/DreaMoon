# ADR-002：物品副本使用獨立 store

- 狀態：Accepted
- 日期：2026-08-31
- 相關版本：產品 V3–V5；ItemCopy schema V1

## 背景

物品副本、持有人、歷史與手動等級選擇會持續擴充。直接把它們加入已發布的主 store，會增加主 schema 遷移和既有物品資料的風險。

## 決策

物品副本資料使用獨立 store，透過穩定的 `itemID`、`copyID` 與 `characterID` 連結主資料。副本目前等級選擇再使用獨立 store，避免改動既有 V5 主 store。

## 影響

- 啟動、備份、刪除與修復必須同時處理多個 store。
- 跨 store 關聯不可假設具備 SwiftData transaction，需提供一致性檢查。
- 物品設定與副本狀態的行為必須在規格中分開描述。

## 後續檢討條件

若未來需要跨資料域原子交易，或副本資料已穩定且有安全的一次性遷移工具，才評估合併 store。
