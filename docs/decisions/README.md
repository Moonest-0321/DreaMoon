# 技術決策紀錄

本資料夾保存會影響架構、資料相容性或跨模組行為的決策。每筆決策只描述一個主題，並保留歷史背景，不因日後改變而刪除。

## 狀態

- `Proposed`：提出但尚未採用
- `Accepted`：目前採用
- `Superseded`：已被新決策取代，但保留作為歷史
- `Deprecated`：不再建議使用，仍保留相容性說明

## 新增決策時

1. 複製 `template.md` 並使用三位數序號。
2. 說明背景、決策、替代方案與影響範圍。
3. 若涉及資料模型、刪除、匯出或遷移，同步更新對應技術文件。
4. 不修改舊決策內容；若決策改變，新增一筆並標記舊決策為 `Superseded`。
