# ADR-003：故事標籤使用文字錨點

- 狀態：Accepted
- 日期：2026-08-31
- 相關版本：產品 V4；StoryPlanning schema V1

## 背景

正文會被插入、刪除與重新編輯，單純保存固定字元位置會使標籤在內容變更後失效。

## 決策

故事標籤保存原始選取文字與 UTF-16 offset。正文變更後，在全文中尋找相同文字，選擇距離原位置最近的候選作為顯示位置。正文內容本身不因標籤而改變語意。

## 影響

- 重複文字可能造成推定位置不準，需保留待確認或修正入口。
- 文字編輯功能必須注意 Swift String 與 AppKit UTF-16 offset 的差異。
- 標籤重定位需納入中文、長文字與重複段落測試。

## 後續檢討條件

若未來編輯器改採結構化段落／區塊識別，可評估使用更穩定的內容 ID，但需提供舊錨點相容轉換。
