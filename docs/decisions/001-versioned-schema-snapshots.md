# ADR-001：保留不可變的 schema 快照

- 狀態：Accepted
- 日期：2026-08-31
- 相關版本：資料 schema V1、V2、V3、V5

## 背景

SwiftData 資料庫需要辨識歷史模型。若直接修改已發布的 schema 型別，未來可能無法正確開啟舊資料，或讓遷移行為受現行程式碼意外影響。

## 決策

每個已發布 schema 保留獨立快照。新增欄位或模型時建立新的 schema 版本、匯入／回填策略與測試；不修改已發布快照以配合現行模型。

## 影響

- `MigrationPlan.swift` 必須同時保存歷史 schema 與現行 schema。
- 產品版本與 schema 版本分開記錄。
- 發布前必須用代表性舊 store 驗證匯入與重新啟動。

## 後續檢討條件

若未來改用全新持久化技術或明確建立一次性資料轉換工具，可重新評估，但仍須保留既有資料的讀取路徑。
