# 功能盤點

> 更新日期：2026-09-14；「已實作」只代表程式中存在，不等於已發布或完成所有人工驗收。

## 已實作

| 領域 | 目前能力 | 主要限制 |
|---|---|---|
| 書櫃 | 書籍卡片、搜尋、新增／刪除、作者資訊、封面、統計 | 尚無雲端同步或協作 |
| 書籍結構 | Book → Volume → Section、排序、新增、刪除與短期 UI Undo | 部分刪除入口繞過集中清理 |
| 編輯器 | 富文字、幕標題、CJK 輸入、字數、0.5 秒 debounce 自動儲存、查找替換、指令與快捷鍵 | 不是通用文件格式編輯器 |
| 右鍵工具 | 剪下／複製／貼上、敘事大綱、修改、草稿、角色、物品／能力設定入口、Apple 寫作工具 | V5 已移除舊組織入口，實機狀態組合仍待冒煙 |
| 角色引用 | `@` 選單、建立／連結／解除角色、穩定 UUID URL、別名、名稱同步、正文跳轉 | 未連結同名文字只供選擇性替換 |
| 角色設定 | 基本資料、別名、能力、外觀、心理、物品、一般／血緣關係、事件與各類歷史 | V5 清除舊組織身分；角色事件刪除尚未接跨 store 協調 |
| 勢力與設定集配置 | 每書預設兩個可改名層級；勢力先指定層級，再依方向選擇可跨級的直接上／下層；支援多上／下層、衝突變更阻止、簡介、高層管理員、其他名單、勢力關係、政治與宗教；每本書可管理設定項目顯示、隱藏與順序 | 名單與分類為自由文字；V5 不連結角色、物品、能力、地點、事件或正文；地點／世界條目只提供基礎欄位 |
| 物品 | 共用物品定義、等級、歷史、多個獨立副本、持有人與副本等級 | 正文物品引用是名稱掃描，不是穩定連結 |
| 能力 | 能力定義、等級、角色進度與時間歷史 | 能力進度位於獨立 store |
| 故事背景 | 世界／時代、前提、衝突、主角目標、主題與自由文字 | 沒有自動抽取或推理 |
| 敘事大綱 | 前傳／主線／支線／後記、單一主線、多階段、正文／手動項目、狀態、安置、橫向畫布、待安置、正文跳轉 | 搜尋、統計與大量操作未完成 |
| 故事標籤 | 正式的伏筆與修改類型、標籤清單、正文定位、失效清理、同視窗 Undo／Redo | 沒有回收狀態、未回收清單或回收位置 |
| 世界時間軸 | 紀元、年／月／日、主副軸、節點、事件、角色、可見性、排序、敘事來源、卡片與節錄 | 和敘事大綱是關聯資料，不是同一筆 |
| 匯出 | 全書／卷／節 TXT、全書 EPUB3 | 目的地寫死為開發者 Downloads |
| 資料相容 | 主 schema 技術 V6（產品 V5）、故事規劃 V7、舊資料匯入、舊 Organization 清除、回填、部分跨 store 修復 | 尚無完整多 store 備份／還原 |

## 伏筆能力的準確描述

目前可以說：「把正文片段標成伏筆，從清單找到它並跳回原文。」

目前不能說：「直接看見所有尚未回收的伏筆。」因為資料模型沒有回收狀態、回收正文位置、回收時間或狀態篩選。這是下一階段產品方向，不是現有功能。

## 優先補強

1. 伏筆生命週期：未回收／已回收、回收位置、篩選、統計及失效語意。
2. 匯出目的地選擇與錯誤回饋。
3. 所有結構／事件刪除入口統一接入集中清理。
4. 六個 store 的備份、還原與一致性驗證。
5. 大型群像資料、重複名稱與長篇正文的效能及 UI 壓力測試。
