# DreaMoon V2.3「UI/UX 優化」PRD

狀態：Draft  
版本：V2.3  
日期：2026-08-06

## 1. 範圍

V2.3 只改善目前小說編輯器的 UI/UX，不新增新的產品模組。

現有內容層級固定為：

> 書籍 → 卷 → 節 → 幕

- 卷：內容分組。
- 節：目前的主要編輯單位，會出現在目錄、計算字數與進行前後切換。
- 幕：正文中的標題段落，只是文字格式，不是獨立資料，不計入節次，也不出現在目錄。

以下項目不屬於 V2.3：設定集功能、大綱系統、新內容層級、世界觀模組、資料模型調整。

## 2. 尚未完成的工作

### 2.1 新書與空狀態

- 新建書籍時自動具備可寫作的「第一卷／第一節」。
- 新建完成後直接進入第一節，或提供清楚的開始寫作主按鈕。
- 書櫃無書籍時提供「建立第一本小說」主按鈕。
- 空卷提供「新增第一節」主按鈕。
- 書籍總覽進入編輯器時，直接選取正確的第一個可寫作節。

驗收：新建書籍到輸入正文不超過兩次主要操作；沒有書籍、沒有卷、沒有節時都有明確下一步。

### 2.2 目錄的可發現性

- 統一卷列、節列的縮排、選取背景、拖曳把手與新增節按鈕。
- 提高卷列與節列的可點擊範圍，不依賴精準點擊小圖示。
- 統一新增、重新命名、刪除操作的文字與 icon。
- 拖曳排序時，清楚顯示插入位置。
- 確認卷、節、幕在所有畫面中不會互相混淆。

### 2.3 視覺層級與色彩

- 統一書籍卡片、書籍總覽與編輯器的圓角、陰影、間距與背景。
- 深色模式降低粉彩色的飽和度，保留單一主強調色。
- 提高次要文字、日期、字數、分隔線與選取狀態的可讀性。
- 統一節標題、幕標題與正文的字級、重量與上下間距。
- 正文維持畫面中心，低頻操作不搶正文注意力。

### 2.4 視窗適應與可及性

- 窄視窗下優先保留正文，左右欄可以收合。
- 不同視窗寬度下不出現正文過窄、工具列擁擠或控制項無法點擊。
- 鍵盤焦點清楚可見。
- VoiceOver 能讀出卷、節、幕標題與主要操作名稱。
- 儲存狀態、字數與目前位置固定在穩定區域，不因更新造成畫面跳動。

## 3. V2.3.0：寫作入口

只處理新書、書櫃、書籍總覽與空狀態，讓使用者能快速開始寫作。

### 交付內容

1. 新書建立後有第一卷與第一節。
2. 新書建立後可直接開始寫作。
3. 書櫃、空卷、無選取節都有明確空狀態。
4. 新增第一節後立即選取並顯示編輯器。
5. 文案統一為「卷／節／幕」，不使用「章節」或「大綱」。

## 4. V2.3.1：導覽與視覺

只處理既有元件的清楚度與一致性：

- 目錄縮排、選取、收合、拖曳與點擊範圍。
- 書籍卡片、總覽與編輯器的顏色、圓角、陰影與間距。
- 節標題、幕標題、正文的排版層級。
- 深色模式對比與選取色。
- 正文可讀寬度與工具列視覺優先級。

驗收：使用者能一眼知道目前的卷、節、正文狀態，且正文仍是畫面焦點。

## 5. V2.3.2：長時間寫作細節

只處理現有功能的細節，不新增新的系統：

- 優化現有卷／節排序與連續調整的回饋。
- 優化連續切換節時的目前位置提示。
- 優化現有儲存失敗與刪除確認的回饋。
- 避免狀態更新造成正文跳動、游標移動或視窗重排。
- 補齊現有主要操作的鍵盤焦點與 VoiceOver 標籤。
- 修正窄視窗下的文字截斷、工具列擁擠與不可點擊控制項。

## 6. 明確排除

V2.3 全系列不處理：

- 設定集分類、欄位、資料模型與功能完善。
- 設定集新增、編輯、刪除流程重做。
- 大綱系統或新的內容層級。
- 世界觀首頁、地圖、任務、技能樹、資產管理器。
- 將幕改成獨立資料節點。
- 修改現有 TXT／EPUB 的內容結構。

## 7. 開發順序

1. V2.3.0：完成新書、空卷、空書櫃與開始寫作流程。
2. V2.3.1：完成目錄、編輯器與書櫃的視覺與導覽優化。
3. V2.3.2：完成長時間寫作、可及性與窄視窗驗收。
4. 以實際流程測試：建立書籍、建立節、輸入正文、建立幕、切換節、關閉再開啟。
